Artikel ini merangkum cara menulis heading, blok kode, dan elemen kecil seperti tooltip, sekaligus berfungsi sebagai post contoh untuk mengecek tampilan tema.

Coba arahkan kursor ke kata <dfn info="Tooltip ini dibuat dengan atribut info pada tag dfn" tabindex="0">ini</dfn> untuk melihat tooltip-nya.

## Heading di Markdown

Heading ditulis dengan tanda `#`. Jumlah tanda menentukan tingkatnya:

```markdown
# Heading 1
## Heading 2
### Heading 3
```

Judul artikel sudah dibuat otomatis oleh layout sebagai heading 1, jadi di dalam isi tulisan sebaiknya mulai dari `##`. Dengan begitu satu halaman hanya punya satu `h1`, yang lebih baik untuk SEO dan aksesibilitas.

## Tooltip dengan dfn

Untuk memberi keterangan tambahan pada sebuah kata, gunakan tag `<dfn>` dengan atribut `info`:

```html
<dfn info="Keterangan tambahan" tabindex="0">Hover</dfn> me.
```

Atribut `tabindex="0"` membuat tooltip tetap bisa muncul di layar sentuh dan lewat keyboard, bukan hanya saat di-hover dengan mouse.

## Blok kode

Blok kode diawali dan diakhiri tiga tanda backtick. Tulis nama bahasa tepat setelah backtick pembuka agar Jekyll memberi warna syntax yang sesuai.

### Contoh Python

```python
def quote():
    # Socrates
    print('The only true wisdom is in knowing you know nothing.')
```

### Contoh HTML

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>quote</title>
</head>
<body>
    <!-- Maya Angelou -->
    <p>Try to be a rainbow in someone's cloud.</p>
</body>
</html>
```

### Contoh C

```c
#include <stdio.h>
int main()
{
    // Confucius
    printf("Everything has beauty, but not everyone sees it.\n");
    return 0;
}
```

## Ringkasan

- Mulai heading di dalam isi dari `##`.
- Selalu tulis nama bahasa pada blok kode.
- Beri `tabindex="0"` pada `<dfn>` agar tooltip bisa diakses di HP dan lewat keyboard.
