# Setup dan Instalasi Odoo untuk Development Lokal

Catatan ringkas cara menyiapkan Odoo di mesin lokal dari nol, lalu membuat dan memasang modul custom pertama. Cocok sebagai panduan cepat untuk pemula.

## Gambaran Umum

Odoo adalah aplikasi ERP berbasis Python dengan database PostgreSQL. Fitur custom tidak dibuat dengan mengubah kode inti, melainkan lewat **modul (addon)** yang dipasang di atas Odoo. Dengan begitu, upgrade versi tetap aman.

Alur kerjanya:

1. Siapkan lingkungan (Python, PostgreSQL, library pendukung)
2. Ambil source code Odoo
3. Buat virtual environment dan instal dependency
4. Tulis file konfigurasi `odoo.conf`
5. Jalankan Odoo
6. Buat modul custom dan instal

## Yang Perlu Diinstal

| Software | Fungsi | Catatan |
|---|---|---|
| Git | Mengambil source Odoo dan version control | Wajib |
| Python 3.10+ | Bahasa utama Odoo | Odoo 17 dan 18 butuh 3.10 ke atas |
| PostgreSQL | Database | Versi 12 ke atas, 14 sampai 16 aman |
| Library build | Compile dependency (lxml, psycopg2, dll.) | `build-essential`, `libpq-dev`, `libxml2-dev`, `libxslt1-dev`, `libldap2-dev`, `libsasl2-dev`, `libjpeg-dev` |
| wkhtmltopdf | Cetak laporan PDF | Opsional untuk tahap awal |
| VS Code | Editor | Pasang ekstensi Python dan XML |
| DBeaver atau pgAdmin | Melihat isi database | Opsional |

Kebutuhan mesin: RAM minimal 4 GB (disarankan 8 GB) dan ruang disk sekitar 10 GB.

## Langkah 1: Siapkan Sistem

Untuk Windows, gunakan **WSL2 dengan Ubuntu** karena jauh lebih mudah dibanding instalasi native. Di PowerShell (Administrator):

```powershell
wsl --install -d Ubuntu-22.04
```

Restart, buat user Ubuntu, lalu semua langkah berikutnya dijalankan di terminal Ubuntu. Simpan project di `/home/namauser/...`, bukan di `/mnt/c/...`, supaya lebih cepat.

Instal paket dasar:

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y git python3 python3-pip python3-venv python3-dev \
  build-essential libpq-dev libxml2-dev libxslt1-dev libldap2-dev \
  libsasl2-dev libjpeg-dev zlib1g-dev libffi-dev libssl-dev \
  postgresql postgresql-client wkhtmltopdf
```

Jika Python bawaan masih 3.8, pasang 3.10 berdampingan (jangan menimpa Python sistem):

```bash
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt update
sudo apt install -y python3.10 python3.10-venv python3.10-dev
```

## Langkah 2: Siapkan PostgreSQL

```bash
sudo systemctl start postgresql    # di WSL2: sudo service postgresql start
sudo -u postgres createuser -s $USER
```

Perintah kedua membuat user database dengan nama sama seperti user Linux Anda, sehingga Odoo bisa masuk tanpa password di lingkungan lokal.

## Langkah 3: Ambil Source Code Odoo

Pilih branch sesuai versi yang Anda pakai (contoh 17.0):

```bash
mkdir -p ~/odoo-dev && cd ~/odoo-dev
git clone https://github.com/odoo/odoo.git --depth 1 --branch 17.0 odoo
mkdir custom_addons
```

Folder `custom_addons` adalah tempat semua modul buatan sendiri.

## Langkah 4: Virtual Environment dan Dependency

```bash
cd ~/odoo-dev
python3.10 -m venv venv
source venv/bin/activate
pip install --upgrade pip wheel setuptools
pip install -r odoo/requirements.txt
```

Jika `psycopg2` atau `lxml` gagal dipasang, biasanya ada paket `-dev` yang belum terinstal di Langkah 1.

## Langkah 5: Buat `odoo.conf`

Simpan di `~/odoo-dev`, sejajar dengan folder `odoo` dan `custom_addons`. Perintah ini mengisi path dan nama user otomatis:

```bash
cd ~/odoo-dev
cat > odoo.conf << EOF
[options]
addons_path = $HOME/odoo-dev/odoo/addons,$HOME/odoo-dev/custom_addons
db_host = False
db_port = False
db_user = $(whoami)
db_password = False
db_name = odoo_dev
http_port = 8069
admin_passwd = ganti_password_master_ini
EOF
```

Penjelasan singkat:

- `addons_path`: daftar folder pencarian modul, dipisah koma. Folder `custom_addons` wajib ada di sini.
- `db_user`: harus sama dengan user PostgreSQL yang dibuat di Langkah 2.
- `admin_passwd`: master password untuk Database Manager. Ganti dengan milik Anda sendiri.

## Langkah 6: Jalankan Odoo

```bash
source venv/bin/activate
./odoo/odoo-bin -c odoo.conf -d odoo_dev -i base --stop-after-init
./odoo/odoo-bin -c odoo.conf -d odoo_dev --dev=all
```

Buka `http://localhost:8069`. Jika halaman login muncul, instalasi berhasil. Opsi `--dev=all` membuat perubahan kode dimuat ulang otomatis.

Untuk menghentikan server, tekan `Ctrl + C` di terminal tempat Odoo berjalan.

## Langkah 7: Membuat dan Memasang Modul Custom

Struktur modul minimal:

```
custom_addons/library_simple/
├── __init__.py
├── __manifest__.py
├── models/
│   ├── __init__.py
│   └── library_book.py
├── views/
│   └── library_book_views.xml
└── security/
    └── ir.model.access.csv
```

Isi file inti:

`__init__.py` di root modul:

```python
from . import models
```

`models/__init__.py`:

```python
from . import library_book
```

`__manifest__.py`:

```python
{
    'name': 'Perpustakaan Sederhana',
    'version': '1.0.0',
    'category': 'Services',
    'depends': ['base'],
    'data': [
        'security/ir.model.access.csv',
        'views/library_book_views.xml',
    ],
    'application': True,
    'installable': True,
    'license': 'LGPL-3',
}
```

`models/library_book.py`:

```python
from odoo import models, fields


class LibraryBook(models.Model):
    _name = 'library.book'
    _description = 'Buku Perpustakaan'

    name = fields.Char(string='Judul', required=True)
    author = fields.Char(string='Penulis')
    isbn = fields.Char(string='ISBN')
```

`security/ir.model.access.csv`:

```csv
id,name,model_id:id,group_id:id,perm_read,perm_write,perm_create,perm_unlink
access_library_book_user,library.book user,model_library_book,base.group_user,1,1,1,0
access_library_book_admin,library.book admin,model_library_book,base.group_system,1,1,1,1
```

`views/library_book_views.xml` (sintaks Odoo 18; untuk Odoo 17 ganti `<list>` menjadi `<tree>` dan `list,form` menjadi `tree,form`):

```xml
<odoo>
    <record id="library_book_view_list" model="ir.ui.view">
        <field name="name">library.book.list</field>
        <field name="model">library.book</field>
        <field name="arch" type="xml">
            <list>
                <field name="name"/>
                <field name="author"/>
                <field name="isbn"/>
            </list>
        </field>
    </record>

    <record id="library_book_view_form" model="ir.ui.view">
        <field name="name">library.book.form</field>
        <field name="model">library.book</field>
        <field name="arch" type="xml">
            <form>
                <sheet>
                    <group>
                        <field name="name"/>
                        <field name="author"/>
                        <field name="isbn"/>
                    </group>
                </sheet>
            </form>
        </field>
    </record>

    <record id="library_book_action" model="ir.actions.act_window">
        <field name="name">Buku</field>
        <field name="res_model">library.book</field>
        <field name="view_mode">list,form</field>
    </record>

    <menuitem id="library_menu_root" name="Perpustakaan" sequence="10"/>
    <menuitem id="library_menu_books" name="Buku"
              parent="library_menu_root" action="library_book_action"/>
</odoo>
```

Instal modul:

```bash
./odoo/odoo-bin -c odoo.conf -d odoo_dev -i library_simple --dev=all
```

Setelah mengubah model atau view, jalankan update dengan `-u`:

```bash
./odoo/odoo-bin -c odoo.conf -d odoo_dev -u library_simple --dev=all
```

Alternatif lewat antarmuka: aktifkan Developer Mode, buka `Apps`, klik **Update Apps List**, cari modulnya, lalu **Install**.

## Melihat Database dengan DBeaver

Agar bisa terhubung lewat TCP, beri password pada user PostgreSQL:

```bash
sudo -u postgres psql -c "ALTER USER $(whoami) PASSWORD 'password_kuat_anda';"
```

Di DBeaver buat koneksi PostgreSQL dengan host `localhost`, port `5432`, database `odoo_dev`, serta user dan password di atas. Tabel modul ada di `Schemas → public → Tables`, misalnya `library_book`. Gunakan koneksi ini untuk memeriksa data saja, dan lakukan perubahan lewat Odoo atau ORM.

## Masalah yang Sering Muncul

| Gejala | Penyebab dan solusi |
|---|---|
| `role "xxx" does not exist` | User PostgreSQL belum dibuat; jalankan `createuser -s` |
| Modul tidak muncul di Apps | `addons_path` salah atau belum klik Update Apps List |
| `No matching record found for external id 'model_library_book'` | Model belum diimpor di `__init__.py`, atau `_name` salah ketik |
| `Missing required value for the field 'Model' (model_id)` | Format CSV hak akses rusak (header salah, kolom kosong, BOM, atau pemisah bukan koma) |
| `Address already in use` | Port 8069 masih dipakai; cek dengan `ss -tlnp \| grep 8069` |
| `ParseError` pada view | Tag `<list>` dan `<tree>` tidak cocok dengan versi Odoo |
| Perubahan tidak terlihat | Restart server untuk Python, dan jalankan `-u nama_modul` untuk field atau XML baru |

## Ringkasan Perintah

| Kebutuhan | Perintah |
|---|---|
| Aktifkan venv | `source venv/bin/activate` |
| Jalankan Odoo | `./odoo/odoo-bin -c odoo.conf -d odoo_dev --dev=all` |
| Instal modul | `... -i nama_modul` |
| Update modul | `... -u nama_modul` |
| Cek proses | `ps aux \| grep [o]doo-bin` |
| Hentikan server | `Ctrl + C` atau `kill <PID>` |
| Backup database | `pg_dump -Fc odoo_dev > odoo_dev.dump` |

## Penutup

Dengan lingkungan ini, Anda sudah punya dasar untuk mengembangkan fitur custom: menambah model, view, hak akses, hingga integrasi dengan sistem lain. Langkah berikutnya yang bisa dipelajari adalah relasi antar model (Many2one, One2many), inheritance model bawaan seperti `sale.order`, laporan PDF dengan QWeb, dan endpoint API lewat controller.
